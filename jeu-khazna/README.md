# 🔐 الخزنة — ألغاز جماعية أونلاين (النموذج الأوّلي)

لعبة تعاونية للاعبَين: **المشغّل** يرى الأقفال بلا دليل، و**الخبير** معه الدليل ولا يرى الأقفال.
لا يُحلّ أي لغز إلا بالكلام والتعاون. أمامكما **10 دقائق** لفتح **5 أقفال**، وكل خطأ يكلّف 30 ثانية.

## الغرف الخمس
| # | الغرفة | المشغّل يرى | الخبير يرى |
|---|---|---|---|
| 1 | باب الرموز | 4 رموز + لوحة أرقام | جدول رمز ← رقم |
| 2 | صندوق الأسلاك | 3 إلى 6 أسلاك ملوّنة | قواعد القطع حسب عدد الأسلاك |
| 3 | المخطوط المشفّر | كلمة مشفّرة + رمز | جدول الإزاحة + الأبجدية |
| 4 | السرداب المظلم | أسهم فقط (ظلام) | خريطة المتاهة ومكان المشغّل |
| 5 | قفل الأضواء | أضواء تومض + 4 أزرار | جدول تحويل الألوان لكل مرحلة |

**كل الألغاز تتغيّر في كل لعبة** (مولّد حتمي من بذرة)، فلا يمكن حفظ الحلول.

## التشغيل
اللعبة ملفات ثابتة (HTML/CSS/JS)، بلا بناء ولا تثبيت.

**تجربة محلية فوراً** (تبويبان في نفس المتصفح):
```bash
cd jeu-khazna
python3 -m http.server 8765
# افتح http://localhost:8765 في تبويبين: أنشئ غرفة في الأوّل وادخل برمزها في الثاني
```

**اللعب بين هاتفين (أونلاين)**:
1. أنشئ مشروعاً مجانياً في Supabase.
2. ضع رابط المشروع والمفتاح العام (anon / publishable) في `config.js`.
3. انشر المجلّد على أي استضافة ثابتة (Netlify أو Vercel).

يستعمل الاتصال Supabase Realtime (قنوات Broadcast)، ولا يحتاج جداول.

## الاختبارات
```bash
cd jeu-khazna && npm test
```
تحلّ 500 لعبة كاملة تلقائياً وتتحقّق من العقوبات والاصطدامات وانتهاء الوقت.

## البنية
- `core.js`: منطق اللعبة الصافي (توليد الألغاز، القواعد، العقوبات)، مشترك مع الاختبارات.
- `app.js`: الواجهة. منشئ الغرفة هو **المرجع**: يطبّق الأفعال ويبثّ الحالة، والضيف يرسل أفعاله فقط.
- `net.js`: الاتصال (Supabase أونلاين، أو BroadcastChannel للتجربة المحلية).

## حدود النموذج الأوّلي
- لاعبان فقط. اللعب بـ 4 لاعبين ونمط السباق بين فريقين في المرحلة القادمة.
- لا يوجد صوت داخل اللعبة: تكلّما عبر مكالمة أو في نفس المكان.
- اللاعب الذي يعرف البرمجة يستطيع رؤية الحلول من أدوات المطوّر. هذا مقبول للتجربة بين الأصدقاء، وسيُعالج بخادم مرجعي في النسخة النهائية.

## المراحل القادمة
1. **اختبار المتعة**: هل يضحك اللاعبون ويتحمّسون؟ (هذا هو هدف هذا النموذج)
2. 4 لاعبين بأدوار إضافية، ونمط سباق فريق ضدّ فريق، وترتيب.
3. نقل اللعبة إلى Godot للنسخة النهائية (رسوم، أصوات، تطبيق Android)، مع خزنة الأسبوع والمواسم.

## النسخة الأصلية لأندرويد (Flutter) — `app_flutter/`
تطبيق أصلي 100% بنفس منطق اللعبة (نسخة Dart مطابقة لـ `core.js`: نفس البذرة تعطي نفس الألغاز، فيمكن للويب والتطبيق اللعب معاً أونلاين).

**ما فيه زيادة على نسخة الويب:** شرح تفاعلي في البداية، وضع «هاتف واحد» مع زرّ تبديل الدور، اهتزازات، حركات انتقال بين الأقفال، اهتزاز الشاشة عند الخطأ، وشاشة فتح الخزنة.

**تحميل الـ APK:** كل تحديث لمجلّد `app_flutter/` في فرع `jeu-khazna` يشغّل البناء الآلي في GitHub Actions
(تبويب Actions ← «Khazna APK» ← آخر تشغيل ← Artifacts ← `khazna-apk`).

**تفعيل اللعب أونلاين في الـ APK:** أضف في إعدادات المستودع (Settings ← Secrets and variables ← Actions) سرّين:
`SUPABASE_URL` و`SUPABASE_ANON_KEY`. بدونهما يعمل وضع «هاتف واحد» فقط.

**البناء محلياً:**
```bash
cd jeu-khazna/app_flutter
flutter create --platforms=android --org com.khazna --project-name khazna .
flutter test
flutter run --dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...
```
بعد `flutter create` أضف إذن الإنترنت في `android/app/src/main/AndroidManifest.xml` (الـ CI يفعل ذلك آلياً).

**تطابق النسختين:** `node tools/gen-dart-vectors.mjs` يولّد ألغازاً مرجعية من `core.js`، واختبارات Dart تتحقّق أن النسخة الأصلية تولّد نفس الألغاز.
