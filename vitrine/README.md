# Site vitrine — collection

Page unique (`index.html`), sans serveur : elle lit le catalogue public dans Supabase (`vitrine_catalogue`).
Tout ce qui est ajouté dans le stock du logiciel (modèles, couleurs, tailles, photos) apparaît automatiquement.

## Mise en ligne (une seule fois)
**Vercel** : New Project → importer `charuadejsi-del/fares` → branche `broderie-flutter` → Root Directory `vitrine` → Framework *Other* → Deploy.
Ou **Netlify Drop** : glisser le dossier `vitrine` sur https://app.netlify.com/drop.

Puis coller l'adresse obtenue dans le logiciel : Réglages → Entreprise → Site vitrine.

Lien direct vers un modèle : `https://votre-site/?m=ROB-0001`
